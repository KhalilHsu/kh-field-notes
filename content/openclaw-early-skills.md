刚开始用 OpenClaw 那段时间，我基本每天都在跟它聊，有时候停不下来，聊到凌晨两三点都有。就是在那段时间里，我第一次想着给自己做几个 Skill。

不是要做什么通用的工具，就是按照自己的使用习惯来。我做了两个：

![Article Summarizer Plus](media/skill-article-summarizer.png)
![UI Inspiration Library](media/skill-ui-inspiration.png)

**Article Summarizer Plus**，是因为我订阅了不少 Newsletter，但经常懒得打开，不知道值不值得读。我希望 OpenClaw 能帮我先过一遍，告诉我这篇讲了什么，我再决定要不要认真看。

**UI Inspiration Library**，是因为我一直有收集 UI 截图的习惯，存到 Notion 里，但积累多了之后根本找不回来。想做个黑金配色的 Pricing 页参考，翻半天也翻不到。这个 Skill 就是让 OpenClaw 帮我存图的时候顺手打好标，之后要找直接搜就行。

两个 Skill 发到 ClawHub 之后，有点出乎意料——到现在加起来已经有几千次下载了，每天还有人在装。可能是因为这两个场景足够通用，很多人都有类似的使用习惯。

BTW，Skill 和 Sandbox 可能是 25 年我觉得最牛逼的两个 AI 产品层面的尝试了。

如果你也有同样的需求，可以直接装来用：

```sh
openclaw skills install @khalilhsu/article-summarizer-plus
openclaw skills install @khalilhsu/ui-inspiration-library
```
