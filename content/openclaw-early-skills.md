那段时间我几乎每天都在用 OpenClaw，基本聊到凌晨两三点才停。就是那段时间，我第一次有了「给自己做 Skill」的念头。

不是因为要做什么很厉害的东西，就是两个很实际的使用场景。

![Article Summarizer Plus](media/skill-article-summarizer.png)
![UI Inspiration Library](media/skill-ui-inspiration.png)

**Article Summarizer Plus**，是因为我特别喜欢看订阅的文章。我有一堆 Newsletter，但不是每一篇都值得完整读完。我希望 OpenClaw 能帮我先过一遍，告诉我这篇讲了什么，值不值得认真看。就是这么简单的需求。

**UI Inspiration Library**，是因为我平时会收集很多觉得不错的 UI，截图存到 Notion 里。但时间一长，根本找不回来。想做个黑金风格的 Pricing 页的时候，完全不知道去哪翻。做这个 Skill 就是想让 OpenClaw 帮我把图片存进去的时候顺便打好标，之后要找的时候直接搜。

两个 Skill 都发到了 ClawHub，如果有类似使用习惯的话可以装来试试：

```sh
openclaw skills install @khalilhsu/article-summarizer-plus
openclaw skills install @khalilhsu/ui-inspiration-library
```
