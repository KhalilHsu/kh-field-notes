最近高强度用了很多 Personal Agent，但基本上都弃用了。

从 ChatGPT 到 Agent 再到现在的 Personal Agent，迭代了这么多轮，落到眼前的依然只是一个对话框。有人觉得把底层 session 包成聊天 GUI 是偷懒，也有人觉得这很本质。但我用下来的体感很诚实：**对于越来越强的 AI 和 Agent 而言，对话并不是一个好桥梁，这个桥梁一定会变。**

---

拿对话去承载一个越来越强的 Agent，越往深处用，越别扭。我自己最痛的两个点，一个是**并行讨论**，一个是**可追溯性**。

### **并行讨论**

真实的工作从来不是单线程的。一件事聊到一半突然冒出新想法，或者要拆出一条支线去查证，现在的工具立刻会把一道别扭的选择题甩给我：**到底该在当前窗口接着聊，还是点一下“新建对话”另开一个 session？** 接着聊上下文瞬间糊成一锅粥，另开又把背景全切碎了，怎么选都不自然。

换位想想，如果身边真有一个很牛的助手，**我根本不需要在开口前提醒他“等等，接下来我要跟你讲一件新事情，请你开个新频道”。** 我只需要把想到的事直接抛给他，他自己就应该懂得判断、懂得路由，而不是让人来替系统管理 session。

### **可追溯性**

对话是一维的时间线，天然是“往前滚、滚过去就忘”的。跟 Agent 协作了几天之后，想回头找之前敲定过的一个结论，或者复盘某个方案是怎么一步步推演出来的，面对的往往是几百屏混杂着过程噪音、废话和工具调用的聊天记录——要么一条条往上翻，要么在一排长得一模一样的侧边栏标题里盲猜。真正有价值的决策和产物，全被埋在了流水账里。

到现在为止，业界对并行讨论和可追溯性这两个问题，其实都还没有什么像样的解法。

### **更本质的结构错配**

如果再往底层挖一层，对话还有一个更根本的问题：

> 用户每一次输入的 query，优先级和体量本就是天差地别的——可能只是随口问个天气，也可能是拆解一份关键的销售数据，延伸出几十轮追问与决策。**但“对话”这种交互形式却是同等体量的。** 它不分轻重缓急，把不同权重、不同生命周期的内容，全都压扁成了同一条时间线里长得一模一样的气泡。

---

我一直挺喜欢对未来做点预测。顺着这些痛点往下推，我觉得未来人与 Agent 之间的桥梁，至少会有两个变化。

有一点我很确定：**进入一个 AI Native 的工具，里面只有一个输入框和一段对话，是完全不对的。**

**第一，Input 还会存在，但它的交互形态一定会远远超出打字和说话。**

前几天刚写过 [《我好像有点不会打字了》](../forgetting-how-to-type/)，语音已经快把键盘挤成遥控器了。但哪怕靠说话，人依然得费劲把脑子里的现状“口述”给 AI。未来的 Input 一定会接进更多维度的输入——比如实时的屏幕共享，甚至更直接的环境展示。对于 Agent 来说，你正在看什么、正处在什么现场，这些不用刻意敲出来的东西，反而才是最重要的上下文。

**第二，对话之外，会出现一个“动态的产物”——而且它本身，会成为下一次输入最重要的 Trigger。**

就像《钢铁侠》里的 Jarvis 一样，它不是呆呆地等在空白框后面，而是在适当的时间，把适当的内容动态呈现在你面前。**这个产物不一定是一张 to-do list，也不一定是一个看板，它一定是千人千面的**——不同的人、不同的项目，长出来的动态产物完全不同，并且会随着后台 Agent 的推进持续演化。

它也能消解今天最让人疲惫的“空白框负担”。你不用每次硬想现在该问点什么，扫一眼眼前这份活着的产物，自然就知道哪里该纠偏、哪里值得深挖。**这个动态产物本身，就是激发你继续在 Input 里输入的重要 trigger。**

---

顺着往下推，很自然就会想到：如果未来真有这样的动态产物，App 是不是就不太关键了？

确实很多人说 App 已经名存实亡、迟早会被 AI 吞噬，但我没太想明白。App 从来不只是一套界面，它是商业模式，背后牵着复杂的上下游利益。技术很难直接推翻商业模式，市场和商业总会自己迭代出效率最高的解法——我们今天想出来的“理想交互”，未必是终点。

说到底，我确实很喜欢做预测，但这次反而有点犯难。

十年前腾讯发布微信小程序的时候，我当时就冒出了一个很笃定的判断：这是一家非常牛逼的公司，它一定能活很久——**因为它敢直接在苹果 App Store 的规则头上拉屎。** 而且它真有这个底气。因为几乎每个中国人都离不开微信，但不是每个中国人都非要用 iPhone 不可。在商业世界里，这种**不可替代性**才是最关键的东西。

可放到今天的 AI 时代，我虽然很确定对话框一定会被改写，却完全不知道，到底要怎样牛逼的公司，才能做出什么样牛逼的产品，拥有当年微信那种不可替代性。

甚至说得再标题党一点：如果我们想在今天找一个 AI 里的茅台，或者找一个 AI 时代的腾讯——放眼望去，好像还完全找不到。
