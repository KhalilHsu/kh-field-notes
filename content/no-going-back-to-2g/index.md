十多年前，我第一次用上 3G WCDMA（是的，不是 TD-SCDMA）。

只记得那天从联通营业厅出来骑着自行车，掏出我的 Windows Phone 刷微博，页面几乎秒开。那个感觉我到现在都记得。不是微博有什么重要内容，而是之前 2G 实在太慢了，图片要等，网页要等，什么都要等。然后突然有一天，不用等了。

那时候我当然不知道以后会有短视频、直播电商、移动支付、外卖、网约车。如果有人问我，3G 的 killer app 是什么？我答不上来。

但我知道，**2G 回不去了。**

最近用 AI，我经常有类似的感觉。

![十几岁骑着捷安特、第一次用上 3G 的那个中午。AI 生成插画。](first-taste-of-3g-illustration.png)

---

从 Chat，到 GPTs 的 Instruction + Tools，再到 Manus 的云端 Sandbox，AI 开始能用浏览器、操作文件，自己跑一段时间。Claude Code、Codex 把 Terminal、Codebase、Git 接进去，OpenClaw 又接上 Channel、Memory 和长期运行。现在大家又冲向 Personal Agent。

这条路线很明显：**我们一直在给 AI 加东西。**

更多工具、更大权限、更持久的运行环境。电脑、浏览器、文件系统，然后是邮箱、日历、联系人、账号、支付。

什么任务值得一个 Agent 24 小时存在？什么事情能形成长期稳定的 business loop？还没跑明白。只是大家都觉得，它非常重要。

最近 Personal Agent 又火起来，我觉得还有一个很现实的原因：**Chat 和 Coding Agent 可能都不够赚钱，至少还撑不起大家对 AI 的估值和投入。**

Chat 用户很多，但背后一直在烧推理成本。Coding Agent 更接近生产力，用户也愿意付钱，但要靠它撑起下一代计算平台的预期，可能还是不够。

于是继续往外找。进入更多工作流、更多交易，掌握更多个人信息，也获得更强的用户锁定。

Personal Agent 既是能力扩张，也是商业模式焦虑。还没证明它是答案，但大家需要一个更大的答案。

---

AI 现在当然有泡沫。很多估值不是在给今天的现金流定价，而是在给“如果 AI 真的是下一次工业革命，会怎么样”定价。

于是所有人都 FOMO。投资人怕错过，创业者怕错过，大公司怕错过，牛马也怕自己突然变成上一代工种。大量的钱、公司涌进来，真正被验证的商业模式却没几个。

当然泡沫不一定是坏事。在没人知道答案的时候，泡沫就是一种加速器。资本补贴算力，补贴模型，补贴一堆人去试各种可能。大部分东西最后都会死，但一些本来需要十年才能试出来的东西，可能三年就被试完了。

现在这个行业挺矛盾的：**已经有很多非常好的 AI 产品，但还没有那么多非常好的 AI 生意。**

模型贵，Agent 更贵，垂直应用又随时可能被下一代基础模型吃掉。今天很多所谓 moat，可能只是当前模型能力不够时搭出来的脚手架。

但我还是很期待每周又会冒出来什么。从“微博加载快了”，你推导不出后来的抖音和直播电商。今天的 AI 会怎么改变白领工作，when、how，我也不知道。但用过之后，确实越来越回不去了。

泡沫大概也会破。摔的时候别头朝下就行。
